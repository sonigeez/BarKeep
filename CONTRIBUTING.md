# Contributing to BarKeep

1. Open an issue describing the user-facing problem.
2. Keep changes focused and dependency-free.
3. Run `swift build` and `./script/build_and_run.sh --verify`.
4. Verify the click, right-click, shortcut, and auto-collapse paths on a real menu bar when changing status-item behavior.

Do not add analytics, user-content collection, or a network dependency. Those are bugs wearing business-casual clothes.
